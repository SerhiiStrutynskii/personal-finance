# Backlog фабрики

`/factory next` бере перший пункт `- [ ]` без id у дужках. Оркестратор відмічає `- [x] … → <job-id>`
після злиття, а для `needs-human` дописує `(<job-id>)` і лишає пункт невідміченим.

- [x] Меню (1/3) — довідники прийомів їжі й страв на сторінці «Меню» → 001-menu-dictionaries
  - **Прийоми їжі** — довідник домогосподарства (за замовчуванням «Сніданок», «Обід», «Вечеря»); користувач може додавати, перейменовувати, змінювати порядок і видаляти.
  - **Страви** — довідник домогосподарства (напр. «Гречка варена», «М'ясо смажене»). Одиниця страви — порція. Порція описується складом: продукти зі спільного довідника продуктів (того самого, що для списків покупок) і кількість кожного в одиниці продукту (шт, кг, л, уп; дробові значення — напр. 0,15 кг).
  - **Ціна порції** = сума (кількість × ціна продукту з довідника), показується в списку страв. Продукт без ціни рахується як 0, а страва показує позначку, що ціна неповна.
- [x] Меню (2/3) — календар меню на місяць і друк меню на день (потрібна задача «Меню (1/3)»: прийоми їжі й страви) → 002-menu-calendar
  - **Меню** — календар місяця на сторінці «Меню»: на кожен день і прийом їжі додаються страви з довідника з кількістю порцій (за замовчуванням 1); страви можна прибрати або змінити кількість порцій.
  - Вартість дня й місяця = сума (ціна порції × порції); якщо в якійсь страві ціна неповна — позначка біля суми.
  - **Друк меню на день** — окремий вигляд для друку: дата, прийоми їжі, страви, порції, без елементів навігації.
- [x] Меню (3/3) — список покупок і бюджет на продукти за період меню (потрібна задача «Меню (2/3)»: календар меню) → 003-menu-shopping
  - Користувач обирає період: день, тиждень (пн–нд) або місяць.
  - **Список покупок за період** — продукти всіх страв меню за період підсумовуються по продукту (кількість у порції × порції) з орієнтовною вартістю; з нього можна одним кліком створити звичайний список покупок.
  - **Бюджет на продукти** — орієнтовна сума за обраний період; продукти без ціни рахуються як 0, і показується, скільки таких продуктів.
- [x] Зміна пароля: у меню користувача форма «поточний пароль + новий», після зміни інші сесії завершуються → 004-change-password
- [x] Експорт витрат обраного місяця в CSV зі сторінки «Витрати» (дата, сума, категорія, рахунок, опис) → 005-csv-export
- [x] Передача ролі власника домогосподарства іншому учаснику зі сторінки «Домогосподарство» → 006-owner-transfer
- [x] Реорганізація покупок: перенести покупки в модуль «Меню» з двома табами — «Планування раціону» і «Покупки» → 007-menu-shopping-tabs
  - **Планування раціону** — поточний календар меню; у прийом їжі дня, крім страв, можна напряму додати продукт зі спільного довідника продуктів (з кількістю в одиниці продукту), так само як страву.
  - **Покупки** — поточні списки покупок переїжджають у цей таб; окремий пункт «Покупки» в навігації прибирається.
- [x] Меню: вибір місця нового прийому їжі та ширша панель дня → 008-meal-order-day-panel
  - **Місце нового прийому їжі** — у формі «Новий прийом їжі» є поле «Після» зі списком наявних прийомів (за замовчуванням останній), напр. «Сніданок 2» одразу після «Сніданок»; новий прийом стає в обране місце, решта зсуваються. Наявні стрілки ↑/↓ у довіднику лишаються.
  - **Ширша панель дня** — у «Плануванні раціону» назви страв і продуктів у панелі дня не стискаються у вузьку колонку: панель дня стоїть під календарем на всю ширину батьківського блоку (замість правої колонки 24rem на десктопі), назви читаються в один рядок, коли є місце; на телефоні вигляд не гірший за поточний.
- [x] Меню: шаблони меню дня — зберегти меню дня як шаблон і застосувати його до іншого дня → 009-menu-day-templates
  - **Збереження** — у панелі дня «Планування раціону» дія «Зберегти як шаблон»: назва шаблону (напр. «Будній день»), у шаблон потрапляють усі страви й продукти дня з порціями/кількістю по прийомах їжі. Шаблон — довідник домогосподарства; ціни в шаблоні не зберігаються, вартість рахується з поточних цін.
  - **Застосування** — у панелі іншого дня дія «Застосувати шаблон»: вибір шаблону, меню дня **замінюється** вмістом шаблону (з підтвердженням, якщо в дні вже є страви чи продукти). Шаблон застосовується лише до цілого дня, не до окремого прийому їжі.
  - **Керування шаблонами** — список шаблонів (перейменувати, видалити); видалення шаблону не змінює днів, до яких його вже застосували.
